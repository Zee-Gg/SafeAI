# Decisions

## Original decisions (Phase 1 prompt)

| Decision                                                            | Reason                                                                                                       |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **pnpm workspaces**                                                 | Fast installs, and one repo can hold several packages that share code.                                       |
| **Node 24 LTS**                                                     | The current long-term-support version: stable and supported for years.                                       |
| **WXT (React template)**                                            | Handles Manifest V3, hot reload and browser launching, so we write features instead of build plumbing.       |
| **Monorepo, no Turborepo**                                          | Only 3 packages, so a build-orchestration tool would add complexity without real benefit.                    |
| **Tailwind CSS v4, tokens in one CSS file**                         | One place defines every colour and size. Tailwind v4 reads them straight from CSS (`@theme`).                |
| **ESLint flat config + typescript-eslint + react-hooks + jsx-a11y** | Catches bugs, wrong hook usage and accessibility problems while we type.                                     |
| **Prettier + prettier-plugin-tailwindcss + eslint-config-prettier** | Consistent formatting and sorted Tailwind classes, without ESLint and Prettier fighting.                     |
| **WXT auto-launched Chrome with a persistent profile**              | Dev Chrome opens with the extension loaded and remembers the ChatGPT login.                                  |
| **Product name "SafeAI"**                                           | Short name for the UI; "for Teams" comes later.                                                              |
| **TypeScript strict, no `any`**                                     | The compiler catches mistakes early, and types document the code.                                            |
| **Zod for message shapes**                                          | Every message is checked when it arrives, so bad or unexpected data is rejected safely.                      |
| **Only the `storage` permission**                                   | Fewer permissions = less risk and more user trust. The content script is limited to `https://chatgpt.com/*`. |

## Decisions made during Phase 1

| Decision                                                          | Reason                                                                                                                                                                |
| ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ESLint 9, not 10**                                              | `eslint-plugin-jsx-a11y` 6.10 doesn't support ESLint 10 yet. npm marks 9 as "deprecated"; upgrade when jsx-a11y catches up.                                           |
| **TypeScript 6.0, not 7**                                         | `typescript-eslint` 8.x supports TypeScript below 6.1 only. TypeScript 7 is the new Go-based compiler.                                                                |
| **`defineConfig` from `eslint/config`**                           | Current typescript-eslint docs recommend it instead of the older `tseslint.config()` helper.                                                                          |
| **fnm to install Node 24**                                        | The PC already had Node 22. fnm keeps both, and switches automatically using `.nvmrc`.                                                                                |
| **`.prettierrc` in YAML**                                         | JSON can't hold comments; YAML can, and every file starts with an explanatory comment.                                                                                |
| **`.gitattributes` forces LF line endings**                       | Git on Windows would convert files to CRLF, and `format:check` would then fail.                                                                                       |
| **`vite` and `web-ext` added (approved)**                         | WXT 0.21 no longer bundles them. Vite is required to build; web-ext is needed for `pnpm dev` to auto-open Chrome.                                                     |
| **Geist from `@fontsource-variable` (approved)**                  | Local font files bundled with the popup: no CDN, works offline, leaks nothing.                                                                                        |
| **All sizes in px, not rem**                                      | The badge lives on chatgpt.com, where `rem` follows ChatGPT's own root font size.                                                                                     |
| **`--color-*: initial` in the tokens**                            | Removes Tailwind's default palette, so only SafeAI colours can be used.                                                                                               |
| **Strict Zod objects (`z.strictObject`)**                         | A message with an unexpected field (like `text`) is rejected. This is a safety net for the "no prompt text in messages" rule.                                         |
| **Validate messages before sending AND on arrival**               | Privacy mistakes are caught at the source, and bad input never reaches the router.                                                                                    |
| **Background replies with `sendResponse` + `return true`**        | The classic Chrome pattern. It works in every Chrome version.                                                                                                         |
| **`CONTENT_PING` message for the popup's status card (approved)** | Chrome hides `tab.url` without the `tabs` permission. Asking the tab's content script needs no permission.                                                            |
| **`getMode()` parameter on the interceptor (approved)**           | The interceptor decides at the moment of each event whether to block (replace) or only watch (observe).                                                               |
| **Badge at top-right, click-through**                             | Bottom-right (the original plan) covered ChatGPT's input buttons. `pointer-events: none` means it can never block a ChatGPT click; only the error badge is clickable. |
| **Manual `--tw-*` defaults in `ui.css`**                          | Tailwind sets them with `@property`, which Chrome ignores inside Shadow DOM. Without them the badge had no border.                                                    |
| **Badge shadow via `[box-shadow:var(--shadow-lg)]`**              | Same Shadow DOM reason: Tailwind's `shadow-*` classes depend on `@property` variables.                                                                                |
| **Send confirmed by "input box became empty"**                    | ChatGPT empties the box after sending, so this is a reliable "it really went" signal without reading the network.                                                     |
| **One replace at a time (`busy` flag)**                           | Pressing Enter twice quickly must not start two overlapping replacements.                                                                                             |
| **Developer mode must be on**                                     | Chrome 157 doesn't run unpacked extensions' service workers without it.                                                                                               |
| **One short git commit per milestone**                            | Your preference: a clean history that matches the milestones. Pushed to `github.com/Zee-Gg/SafeAI`.                                                                   |

## Phase 2 decisions (detection engine)

| Decision                                                                                     | Reason                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Vitest 5.1.0 + @vitest/coverage-v8 5.1.0**                                                 | Fast, works with Vite and TypeScript, built-in coverage and benchmarks. Pinned to 5.1.0 because 5.1.1 was released the same day and pnpm's supply-chain rule (minimum release age) blocks very new versions; we did not switch that safety rule off |
| **90% lines + branches on packages/detection**                                               | The engine guards private data, so almost every code path must be tested                                                                                                                                                                            |
| **`pnpm test` = with coverage; `test:watch` = without**                                      | The threshold is enforced on every full run; watch mode stays fast while working                                                                                                                                                                    |
| **`pnpm typecheck` stays separate**                                                          | Vitest removes types without checking them                                                                                                                                                                                                          |
| **libphonenumber-js "max" metadata**                                                         | Strict per-country validation and number types (about 145 kB)                                                                                                                                                                                       |
| **Phone finding via `findPhoneNumbersInText`**                                               | The docs describe it as a port of Google's PhoneNumberMatcher: better than a home-made regex                                                                                                                                                        |
| **Aho-Corasick for custom terms**                                                            | Thousands of terms in one pass; library vs our own decided in M5                                                                                                                                                                                    |
| **Token URLs: only the secret part**                                                         | The rest of the URL is useful context for the AI                                                                                                                                                                                                    |
| **National ID = candidate regex + validator**                                                | Cheap finding, strict rejection of impossible numbers                                                                                                                                                                                               |
| **ReDoS protection in layers**                                                               | eslint-plugin-regexp + safe-regex2 test (+ recheck if kept) + chunking + time budget                                                                                                                                                                |
| **Public keys are not secrets**                                                              | Stripe `pk_`, Supabase `sb_publishable_`, Twilio `AC` SIDs are public by design                                                                                                                                                                     |
| **Pure engine**                                                                              | No DOM/chrome/fetch/logging: runs anywhere, easy to test, can't leak                                                                                                                                                                                |
| **No DOM lib in the detection tsconfig**                                                     | Purity enforced by the compiler, not only by ESLint                                                                                                                                                                                                 |
| **Timing: small local type for `performance.now()` + `Date.now()` fallback (in `clock.ts`)** | Sub-millisecond precision for the 30 ms target; the fallback means timing can never crash; a global declaration file would clash with Vitest's Node types                                                                                           |
| **Chunks: 20,000 chars, 500 overlap, cut at whitespace in the last 200 chars**               | No regex on huge strings; fewer tokens cut in half                                                                                                                                                                                                  |
| **Whole-text scope for private-key, JWT and custom terms**                                   | These items can be longer than the overlap; each of these scans is linear                                                                                                                                                                           |
| **PEM keys found with `indexOf`, no regex**                                                  | Guaranteed linear; a BEGIN with no END is still caught (to the end of its line block)                                                                                                                                                               |
| **JWT regex: flat, no nested quantifiers, token-start lookbehind**                           | Linear even on very long text                                                                                                                                                                                                                       |
| **Time budget 500 ms → `complete: false` → not sent**                                        | The extension never sends a message it couldn't fully check                                                                                                                                                                                         |
| **"Warn" items are sent unchanged in Phase 2**                                               | No review UI until Phase 3; they're shown in the Playground and counted in the popup                                                                                                                                                                |
| **Purity checked twice (ESLint + compiler)**                                                 | `no-restricted-globals` + `no-console` in `packages/detection/src`, and no DOM lib, so `document` doesn't even compile                                                                                                                              |
| **Normalization keeps accents with their letter**                                            | "e + ´" and "é" then match the same custom term; positions still map back exactly                                                                                                                                                                   |
| **Raw detections have no `id`; the engine adds it after shifting positions**                 | A detector only knows chunk-relative positions, so a wrong id can never be created                                                                                                                                                                  |
| **`failedDetectors` always returned (ids only)**                                             | Shows which detector broke without ever exposing text; safe in production too                                                                                                                                                                       |
| **Regexes may only start at a token's beginning (lookbehind)**                               | Stops a regex from re-trying at every letter of a long word, the classic slow-regex trap                                                                                                                                                            |
| **Two-level context cache (same object / same contents), max 8**                             | Repeat calls are free; edited policies rebuild; memory stays bounded                                                                                                                                                                                |
| **Overlap: sort by strength, keep with binary search**                                       | Deterministic winners; thousands of findings in milliseconds                                                                                                                                                                                        |
| **Phone: library finder + our own filters as a safety net**                                  | The library already rejects dates, prices, versions…; our filters catch order numbers, currency amounts and Luhn-valid card numbers if it ever lets one through                                                                                     |
| **Keep libphonenumber-js "max" despite +280 kB (+63 kB gzip)**                               | Strict validation was the chosen trade-off; the file loads from disk, not the network; smaller metadata sets exist if size ever matters more                                                                                                        |
| **Card numbers: one consistent separator, 4-4-4-x or 4-6-x shapes**                          | Matches how cards are really written; rejects mixed separators and random digit runs                                                                                                                                                                |
| **IBAN: uppercase only, trimmed back group by group**                                        | IBANs are officially uppercase; trimming handles capital words written right after an IBAN                                                                                                                                                          |
| **Plain 13-digit numbers starting with 1, no CNIC word → skipped**                           | Millisecond timestamps look identical, and national IDs are redacted by default                                                                                                                                                                     |
| **National-ID test values assembled at runtime**                                             | No complete ID-shaped value is ever written in the source                                                                                                                                                                                           |
| **eslint-plugin-regexp's slow-regex warning is treated as a bug**                            | It caught a real polynomial-backtracking pattern in the account-number label; fixed and tested                                                                                                                                                      |
| **API key formats from official docs, with source links in code**                            | Formats change; each row of `api-key-patterns.ts` names its source so it can be re-checked                                                                                                                                                          |
| **Slack: no `xoxa-`/`xoxr-` (not in current docs); added `xapp-`, `xoxe-`, `xwfp-`**         | Follow the provider's current documentation                                                                                                                                                                                                         |
| **Stripe `sk_org_` organization keys detected**                                              | Stripe's docs list them as secret                                                                                                                                                                                                                   |
| **OpenAI legacy `sk-` only with the `T3BlbkFJ` marker**                                      | OpenAI publishes no format; the marker avoids flagging any word starting with `sk-`                                                                                                                                                                 |
| **AWS secret / Twilio auth token only with context (60 chars before)**                       | 40 or 32 random characters are far too common on their own                                                                                                                                                                                          |
| **PEM: label read up to the next `-----`; `PRIVATE KEY BLOCK` (PGP) included**               | Also works for keys pasted inside JSON on one line; PGP keys are equally secret                                                                                                                                                                     |
| **PEM: END search limited to before the next BEGIN**                                         | Keeps the scan linear and stops two keys from merging                                                                                                                                                                                               |
| **Password: quoted + unquoted regexes; placeholders/settings/code skipped**                  | Catches values with spaces; avoids flagging `${VAR}`, `true`, `getenv(…)`                                                                                                                                                                           |
| **Token URLs: `#fragment` parameters too**                                                   | OAuth implicit flow puts `access_token` in the fragment                                                                                                                                                                                             |
| **Entropy candidates: `=` only at the end; hex after hash words skipped**                    | `NAME=value` splits correctly; git hashes and checksums aren't flagged                                                                                                                                                                              |
| **Claude writes code and tests; the user runs every check**                                  | Your request (2026-11-19); commits happen after you confirm the checks pass                                                                                                                                                                         |
| **Own Aho-Corasick (`utils/aho-corasick.ts`)**                                               | Your choice in M5a: `@remusao/aho-corasick` doesn't exist, `ahocorasick` was last released in 2018; we need start+end positions on normalized text, longest match and whole words anyway                                                            |
| **Custom terms prepared once per policy (cached)**                                           | Building the matcher for 5,000 terms is the costly step; every detect() call reuses it                                                                                                                                                              |
| **Duplicate custom terms: first one wins**                                                   | Predictable; the policy editor (later phases) can warn about duplicates                                                                                                                                                                             |
| **Names/addresses: flat trigger regex + code that reads words**                              | Avoids nested quantifiers (slow-regex risk and safe-regex2 failures)                                                                                                                                                                                |
| **Greetings must end at `,` / `!` / line end; "the" is not a name**                          | Fewer false alarms from "Hi Sarah and the team" or "Thanks, The Team"                                                                                                                                                                               |
| **Address: "Dr" isn't a street word; street words followed by map/quote… skipped**           | "Dr" is a title; "Road map" / "Block quote" aren't addresses                                                                                                                                                                                        |
| **Labelled 5-digit postal codes include major PK/UAE cities**                                | Our first markets; a full city list is out of scope                                                                                                                                                                                                 |
| **Time budget starts after policy preparation**       | Preparation is one-time and cached; counting it wrongly stopped the first scan with 5,000 terms (found in your M5 test run). `durationMs` still includes it |
| **ASCII fast path in normalization**                  | Most text is plain ASCII, where NFKC changes nothing; same results, much less work                        |
| **No new test files after M5; M6 skipped**            | Your choice: you test on localhost (Playground, ChatGPT). The 453 existing tests stay; the speed target is checked by hand in the Playground |
| **Playground removed from production via the `entrypoints:resolved` hook** | WXT's include/exclude filter only by browser; you check the production output for playground.html |
| **Playground samples live in `samples.ts`**           | The M6 corpus was skipped; 5 realistic, fully fake samples (keys built at runtime)                         |
| **Popup Playground link only when `import.meta.env.DEV`** | The code is stripped from production; opening a tab needs no permission                                |
| **Replace mode uses the real engine + DEFAULT_POLICY**  | Phase 2 goal 4; a policy editor and company policies come later                                        |
| **Not complete → not sent; block → not sent; write fails → not sent** | If we can't be sure the message is protected, it doesn't leave                               |
| **Observe mode runs detection after the event (setTimeout)** | Logging counts must never delay ChatGPT's own send                                                 |
| **`replacedCount` = occurrences; placeholders numbered in reading order** | Matches what the user sees in the sent message                                      |
| **`countsByCategory` keys restricted to known categories (`z.partialRecord`)** | Metadata only; no free-form keys that could carry text                         |
| **GET_STATUS drops records that don't match today's schema** | Old Phase 1 records would otherwise produce an invalid reply                                       |
| **`test-transform.ts` deleted**                       | Replaced by the real engine + `test-redact.ts`                                                           |
| **M9 final checks are run by you**                    | Your Phase 2 working rule: Claude writes code and docs; you run every check                                |
| **README updated for Phase 2**                        | New packages/scripts (`pnpm test`, Playground) are discoverable from the front page                       |
| **Per-detector timings in DetectResult (`timingsMs`)** | Your 32 ms measurement showed we need to know WHERE the time goes; ids and numbers only, never text      |
| **Phone pre-filter: the library only checks windows around 7+ digit runs** | The library was reading the whole text; most text has few or no phone-like spots                |
| **Aho-Corasick stored in one Map + typed arrays (not one object per node)** | 5,000 terms made ~90,000 objects; garbage collection then slowed the phone detector to 24–29 ms (your M9 timings) |
| **Phone windows < 100 characters apart are merged**   | Each library call has a start-up cost; fewer, slightly longer calls are faster on number-heavy text       |
